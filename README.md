砚藏 PC 0.1.0

1. 使用
双击「砚藏.exe」运行。程序自带运行环境，无需另装 Node 或 Java，角色卡库可离线使用。
请通过软件内置「导入」添加角色卡，不支持把外部文件夹直接复制到程序目录作为导入。

2. 更新
「设置 → 版本更新」可设置更新提醒，点击「打开发布页」可以下载最新更新。

3. 项目地
主页：https://github.com/yanxu-orange/ST-Orange-Yancang-PC
最新版本：https://github.com/yanxu-orange/ST-Orange-Yancang-PC/releases/latest

4. 使用声明

5. 注意事项
资料保存在 pcweb02-data 文件夹，手动更新换版本时把pcweb02-data 文件夹复制到新版本文件夹继承旧数据。
