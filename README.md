# 砚藏 PC

作者：砚梨

砚藏支持保存与管理 SillyTavern 的角色卡。目前提供 Windows x64 版本。

## 下载与使用

[下载最新版本](https://github.com/yanxu-orange/ST-Orange-Yancang-PC/releases/latest)。完整解压 ZIP 到新目录后，双击「砚藏.exe」。程序自带运行环境，无需另装 Node 或 Java，角色卡库可离线使用。

使用软件内置「导入」添加角色卡；不支持把外部文件夹直接复制到程序目录作为导入。

资料保存在程序旁的 `pcweb02-data` 文件夹。换版本前请保留其完整副本，不要用新程序覆盖正在使用的资料。

## 更新

内置自动检查更新，也可在「设置 → 版本更新」手动检查并打开发布页下载。检测需要联网，不会自动下载或安装；GitHub 连接不畅时可尝试 VPN，VPN 并非必需。

## 当前范围

角色卡库已可用；独立世界书库、预设库、快速回复库和聊天记录库尚未开放。
