# 砚藏
砚藏，SillyTavern 个人资源管理器，用于保存与管理角色卡、世界书、预设、快速回复和聊天记录，也可整理画师串图片与提示词。

## 下载
[下载砚藏PC版本](https://github.com/yanxu-orange/ST-Orange-Yancang-PC/releases/latest)
[下载砚藏安卓版本](https://github.com/yanxu-orange/ST-Orange-Yancang/releases/latest)

## 使用
双击「砚藏.exe」运行，角色卡库可离线使用。
请通过软件内置「导入」添加角色卡，不支持把外部文件夹直接复制到程序目录作为导入。

## 更新
「设置 → 版本更新」可设置更新提醒，点击「打开发布页」可以下载最新更新。

## 使用声明
本项目仅供个人非商业使用，请勿二次分发或用于商业用途。
请勿使用砚藏保存、转换或传播付费购得、倒卖而来，或来自商业化平台的资源，包括将此类内容转换为 SillyTavern 格式后再行保存。

## 注意事项
资料保存在 pcweb02-data 文件夹，手动更新换版本时把pcweb02-data 文件夹复制到新版本文件夹继承旧数据。
当前仅开放角色卡库；独立世界书库、预设库、快速回复库和聊天记录库尚未开放。
